# Sales Performance Dashboard using Power BI

## Project Overview
This project is an interactive Sales Performance Dashboard created using Power BI.  
It analyzes car sales data to identify overall revenue, average selling price, top-performing car brands, and regional sales trends.

The dashboard helps convert raw sales data into meaningful business insights through clean and interactive visualizations.

---

## Objectives
- Analyze total and average sales value
- Identify top car brands based on sales
- Understand sales performance across different states
- Create a clear and interactive business dashboard

---

## Dataset
- Format: CSV
- Dataset: Car sales data
- Key columns used:
  - sellingprice
  - make
  - state
  - year
  - odometer
  - condition

---

## Tools & Technologies
- Power BI Desktop
- CSV dataset
- Data modeling and visual formatting in Power BI

---

## Dashboard Visuals
1. Total Sales Value (Card)
2. Average Sales Value (Card)
3. Sales by Car Brand (Bar Chart with Top N filter)
4. Sales by State (Column Chart)
5. Interactive filtering for better analysis

---

## Key Insights
- A small number of car brands contribute to a large portion of total sales
- Average selling price provides a realistic view of market pricing
- Sales performance varies significantly across states
- Power BI dashboards make trends easier to understand than raw data
